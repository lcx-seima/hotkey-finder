# Repository Instructions

## Commit Messages

- Every new, amended, or reworded commit must follow Conventional Commits.
- Use the format `<type>(<scope>): <summary>`; the scope is mandatory.
- Write the type, scope, and summary in English.
- Use a concise, imperative summary without a trailing period.
- Choose an appropriate semantic type such as `feat`, `fix`, `docs`, `refactor`, `test`, `build`, `ci`, `chore`, `perf`, `style`, or `revert`.
- Example: `feat(i18n): add language settings and localized resources`.
